# 小小数独岛

适合 6–12 岁儿童的离线数独小游戏。原生 HTML、CSS、JavaScript，零运行依赖，无广告、无账号、无外部请求。

## 打开就玩

双击 `index.html`，用现代 Chrome、Edge、Firefox 或 Safari 打开。不需要安装 Node、不需要服务器；只复制这一个 HTML 文件也可以玩。

手机浏览器能否直接打开本地 HTML 取决于系统的文件打开方式；若文件预览器不执行脚本，请用支持本地 HTML 的浏览器，或自行部署到普通静态网站。页面本身不需要后端。

## 玩法

1. 选择简单（4×4）、中等（6×6）或困难（9×9）。
2. 点格子，再点底部数字。每行、每列、每个粗线宫里数字不能重复。
3. 题目数字不能修改；填错会温和提醒，不扣分、不限制次数。
4. 可以擦除、撤销或“帮我填一格”。提示优先处理选中的空格或错误格。
5. 返回首页会保留进度；再次打开时点“继续上次的冒险”。

键盘：方向键选格，数字键填写，Backspace/Delete 擦除，Ctrl/Cmd+Z 撤销。

## 计时与成绩

- 只有游戏页处于可见状态时计时；进入后台、首页或确认弹窗会暂停。
- 最佳时间按三个难度分别保存，仅记录没有使用提示的新局。
- 撤销提示数字不会撤销提示次数；重新开始同一道题属于练习局，不更新最佳时间。
- 没有倒计时或失败惩罚；提示局和练习局也会正常庆祝完成。

## 存档与移动端说明

进度和最佳成绩保存在当前浏览器的 localStorage 中，不上传、不跨设备同步。每次有效操作保存，计时每 5 秒补存。清理浏览器数据、更换浏览器或移动 HTML 路径可能失去原来的记录。`file://` 的存储行为因浏览器而异；禁用存储时会提醒，但仍然能玩。

内容最大宽度 480px。功能按钮和数字键盘至少 44×44px；窄屏 9×9 棋盘允许格子小于 44px，以完整显示棋盘、不横向滚动为优先。固定键盘考虑安全区并按真实高度留白；短屏可纵向滚动。支持减少动画偏好。

## 开发与验证

游戏运行不需要开发工具。以下测试使用 Node.js 22 或更新版本：

```sh
node --test tests/sudoku.test.cjs tests/ui.test.cjs
node tests/browser-smoke.cjs
```

浏览器检查使用本机 Chrome 和 Node 内置 WebSocket，无 npm 依赖。Windows 默认 Chrome 路径为 `C:/Program Files/Google/Chrome/Application/chrome.exe`；其他位置可设置 `CHROME_PATH`。辅助脚本会创建独立临时浏览器配置目录，不操作日常浏览器配置。截图输出到系统临时目录。

题库通过独立求解器检验唯一性，再采用数字置换及合法行带、列栈变换；6×6 的宫固定为 2 行 × 3 列，不执行转置。三档名称用于儿童入门分级，不等同于正式的逻辑技巧难度评级。
